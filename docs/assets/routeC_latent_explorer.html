潜空间维数

怎么用这个页面

  1. 选一局：左栏「OOD 检出情况」里点任意一行，右栏就会播那一局的视频，轨迹上出现游标。
  2. 换视角：视频头部的 头部 / 左手 / 右手 三个按钮；判断 OOD 是否合理时先看腕部。
  3. 看判据：拖「阈值 α」滑块，星标、清单、检出计数会同时重算；点 0.12 等预设可快速跳。
  4. 看单条轨迹：勾上「只显示当前轨迹的 OOD 样本」，其它局的星标就不会干扰。
  5. 换维数（页面上方）：16 / 32 / 64 维各有一套 PCA 基，坐标不可跨维数比较。

快捷键：空格 播放/暂停 · ←→ 前后 0.2 s · 123 切视角 · ↑↓ 上/下一局 · Tab 收起侧栏 · Esc 关闭本页

注意：本页要在仓库里原位打开（同目录下有 routeC_latents/）。单独拷一个 html 出去会读不到数据。
