# 路线 C · OOD 评价方案（冻结版 v1）

**状态**：2026-11-26 定稿。此文档是**唯一权威口径**，前端、报告、后续实验都按它执行。
**一句话**：在 VAE 潜空间里，用**按进度条件化的 kNN 新颖度**做统计量，用**分裂共形预测**给出逐帧 `p` 值；
`p < α` 表示"这一帧在当前进度上不像任何正常演示帧"，再用滑窗把逐帧 `p` 变成"是否打断"的判决。

> 变更记录：v0（已废弃）= 用 VAE 重建分 `MSE(dec(μ),x)+βKL` 做统计量。它依赖 2048 维输入，
> 不同训练运行不可比；v1 改用潜空间统计量，只依赖 `Z`，因此**可以先把各维度的 latent 交出去**，
> 由消费方独立复算，口径完全可复现。

## 1. 记号

| 符号 | 含义 |
|---|---|
| $o$ | 一帧观测（三路相机 + 关节状态） |
| $f_\theta$ | 冻结 VLA 的中间表示（2048 维），$f_\theta(o)\in\mathbb{R}^{2048}$ |
| $z = E_\phi(f_\theta(o)) \in \mathbb{R}^d$ | 路线 C 的 VAE **编码器均值**输出，$d$ = 潜空间维数（32/16/8/4） |
| $u \in [0,1]$ | **进度**：该集内归一化时间 $u = (t-t_{\min})/(t_{\max}-t_{\min})$ |
| $\mathcal{D}=\{(z_i,u_i,e_i)\}_{i=1}^{n}$ | 演示（正常执行）帧，$e_i$ 是集号 |
| $\mathcal{F},\ \mathcal{C}$ | 按**集**划分的拟合集（75%，估最近邻参考）与校准集（25%） |
| $\alpha$ | 显著性水平（默认 **0.12**） |

**为什么按进度条件化**：潜空间按执行阶段是**多峰**的（拿耳机 / 挂耳机 / 合笔电 / 交接 / 放入支架各占一坨）。
一个"正常但处在另一阶段"的帧，到全体演示中心的距离同样很大——用全局距离会把"换了阶段"误判成异常。
条件化之后，比较的对象变成"**同一进度上**的正常帧"，语义才对。

## 2. 统计量

对任意帧（其潜变量 $z$、进度 $u$、所属集 $e$）：

$$
s(z,u;\mathcal{F}) \;=\; \sqrt{\ \big\| z - z_{\pi(k)} \big\|_2^2 \ },
\qquad
\pi(1)\le \dots \le \pi(k)
$$

其中 $\{\pi(j)\}$ 是**参考集合**
$\ \mathcal{R}(u,\mathcal{F}) = \{\, i\in\mathcal{F} : |u_i - u| \le \delta,\ e_i \ne e \,\}$
里按 $\|z-z_i\|$ 升序排的索引，$\delta = 0.10$。

- $k=5$；$\delta=0.10$ 用 20 个等宽进度箱实现（查询取相邻 ±2 箱），避免 O(n²) 扫全库。
- **留一集**（$e_i \ne e$）：不让同一条轨迹的前后帧互相"作保"。这一条很重要，
  否则"自己跟自己的前 0.2 秒"总是最近邻，$s$ 会被系统性压低。
- 直觉：$s$ = "在同样的进度上，要跨到第 $k$ 近的正常演示帧，需要偏离多远"。越大越不像。

## 3. 逐帧 p 值（分裂共形预测）

校准集 $\mathcal{C}$ 上算同一统计量（参考集仍用 $\mathcal{F}$，同样留一集）：

$$
p(z,u) \;=\; \frac{1 + \bigl|\{\, i\in\mathcal{C} : s_i \ge s(z,u) \,\}\bigr|}{n_{\mathcal{C}} + 1}
$$

### 3.1 它为什么是"合法 p 值"

共形预测的全部前提只有一条：**可交换性**——在零假设"这一帧与演示帧来自同一分布（且进度条件相同）"下，
待测样本与校准样本是可交换的。于是对任意 $\alpha\in(0,1)$：

$$
\Pr\bigl(p \le \alpha\bigr) \;\le\; \alpha
\qquad\text{（有限样本、无需任何分布假设）}
$$

证明只有三行：$p\le\alpha \iff s$ 能排进校准分数的前 $\lfloor \alpha(n+1)\rfloor$ 名；
可交换性说明 $s$ 在 $\{s_i\}\cup\{s\}$ 里**秩是均匀分布**的，因此取到前 $\alpha$ 部分概率 $\le\alpha$。
分子分母里的 $+1$（含 $s$ 自身）正是让这个不等式在有限 $n$ 下成立的那一项——
少了它，$\Pr(p\le\alpha)$ 会略微超过 $\alpha$。

由此得到的保证是**边际覆盖**：

$$
\mathbb{E}\bigl[\text{被误判的 ID 帧比例}\bigr] \le \alpha
$$

注意三条边界：
1. **不是条件覆盖**。对某一类特定帧（比如某个进度带）没有 $\le\alpha$ 的保证，
   只在整批平均意义上成立；想按进度带控制需要 Mondrian/分组共形。
2. **只对 ID 成立**。对 OOD（失败轨迹）没有任何保证，$\alpha$ 只是"容忍多少误报"的旋钮，
   检测率是经验量，必须实测。
3. **可交换性是前提**。演示集各集之间若不可交换（不同布局、不同操作者），覆盖会破。

### 3.2 与"估计 P(S≥s)"的区别

共形 $p$ 不是 $\hat{\Pr}(S\ge s)$ 的估计，它是**假设检验的 p 值**：在校准集里"有多少个比我还异常"。
两者在 $n$ 大时数值接近，但只有前者带有 $\Pr(p\le\alpha)\le\alpha$ 的保证。文档与图注里不要写成"概率"。

## 4. 从逐帧到"是否打断"（判决规则）

设一集的采样帧序列 $p_1,\dots,p_T$（0.2 s/帧）。取窗口 $W=5$（= 1 s），要求窗内至少 $M=3$ 帧显著：

$$
\tau \;=\; \min\Bigl\{\, t \;:\; \sum_{j=t}^{t+W-1} \mathbf{1}\bigl[p_j<\alpha\bigr] \ge M \,\Bigr\}
$$

- $\tau$ 存在 ⇒ 在 $\tau$ 处打断（交 CAP/人接管）；不存在 ⇒ 认为该集正常。
- $M>1$ 是为了抗单帧抖动（潜空间对帧级噪声敏感）；等价于"1 秒内有 3 个 0.2 s 采样点被判异常"。
- **代价**：这是一个**多帧证据**规则，不继承单帧的 $\alpha$ 误报保证。
  实际误报率必须按"整集"统计（§6），不能拿 $\alpha$ 当集级误报率。
- 另有一个已知副作用：**全局异常**的集（$p$ 中位数本身就低）会在**第一个窗口**就触发，
  此时 $\tau$ 只说明"这集一直不像"，不说明"从哪一步开始错"。写策略时要把两件事分开用。

## 5. 参数（冻结）

| 参数 | 值 | 说明 |
|---|---|---|
| 潜空间维数 $d$ | **32 / 16 / 8 / 4** | 页面上的唯一自由变量；每档一套 VAE + 一套 PCA（仅用于画图） |
| VAE 训练 | demo 100 集 / 10,590 帧，`iters=6000`，`beta=1.0`，seed 0 | 由交接包提供 |
| 最近邻 $k$ | 5 | 太小易受单点噪声，太大把局部结构抹平 |
| 进度带宽 $\delta$ | 0.10（20 箱，取 ±2 箱） | 越小越"局部"，但参考帧不足时退化 |
| 校准比例 | 25%（每 4 集留 1 集） | 与 §4.6 的 75/25 划分一致 |
| 显著性 $\alpha$ | **0.12** | 由扫描确定（见 §6） |
| 窗口 $W$ / 阈值 $M$ | 5 帧 / 3 帧 | 1 s 内 3 个采样点 |

## 6. 评测协议与结果

**协议**：α 固定后再评测；**按集**统计，不按帧。指标 = 失败局检出数、成功局误报数、首触发进度/时刻。

**结果（交接包：100 集 demo / 25 局评测 = 24 失败 + 1 成功；α=0.12 固定）**

| 维数 | 检出 | 误报 | 早触发（进度 <5%） | 首触发进度中位 |
|---|---|---|---|---|
| **32** | **24 / 24** | 0 / 1 | **6** | **26.2%** |
| 16 | 24 / 24 | 0 / 1 | 8 | 21.6% |
| 8 | 24 / 24 | 0 / 1 | 10 | 20.0% |
| 4 | 24 / 24 | 0 / 1 | 11 | 14.4% |

**维度在这里的作用不是"检出与否"，而是"触发时刻有没有判别力"**：四档都 24/24，但低维更早触发
（4 维有 11/24 在进度 5% 以内就报，32 维只有 6/24）。早触发的那部分**只是"这局整体不像"**，
不携带"从哪一步开始错"的信息（§4）。所以若要的是**打断时机**而不只是"能不能拦"，
32 维明显好于 4 维——这修正了"维度完全不是杠杆"的说法：**对检出不是，对时机是**。

**对照（同 8 局、同 α，只换统计量）**

| 统计量 | 检出 |
|---|---|
| 本方案：进度条件 kNN | **7 / 7**，不误报 |
| 全局马氏距离 | 1 / 7 |
| 全局 kNN | 0 / 7（误报 1 局成功） |
| VAE 重建分（v0，另一份 20 集/25 局数据） | 6 / 7（25 局口径下 20/24） |

**必须随结果一起报的局限**
1. **1 局成功** → 误报率无分辨率（要报"误报 <5%"需 ≥60 局成功轨迹）。
2. 单任务 ID、单任务 OOD；结构结论不能外推。
3. 单种子；不同种子下潜空间形状会变（判定指标对维度不敏感，但对种子敏感）。
4. 评测 8 局的分辨率到顶（7/7 之后无法区分四档强弱）。

## 7. 接口契约（前端/下游按这个读）

**输入**：每档一个 `.npz`，字段

```
Z    (n, d) float32    VAE 编码器均值（未做 PCA）
EP   (n,)   int        集号（演示：3100–3199；评测：布局号）
T    (n,)   int        原始帧号（stride 5，25 fps）
CAP  (n,)   str        仅演示集：阶段标签
SUCCESS / SCORE       仅评测集：官方结果
```

- **不需要**交接方算 `p`：消费方用 §2–§3 自行复算，保证口径唯一。
- 若要附带，字段名固定为 `S`（统计量）与 `P`（共形 p），消费方会校验一致性。

**坐标**：画图用的 `PC3` 与本方案**无关**（PCA 只影响可视化，不影响 $p$）——这是 v1 相对 v0 的一个好处：
判定完全在 $d$ 维潜空间里做，不受"3D 只看得到 26% 结构"的影响。
