## 1. 一页速览

| | 现在 |
|---|---|
| **判据** | 冻结 VLA 表征 → VAE 潜变量 $z\in\mathbb R^{32}$ → **局部密度归一化 kNN** 统计量 $s$ → **分裂共形 p 值** → 滑窗 5 帧 ≥3 帧 $p<\alpha$ 判打断（$\alpha=0.12$） |
| **不需要** | 进度 $u$、阶段标签、手工阈值、分布假设 |
| **单任务结果** | 100 集演示 / 25 局评测：**23–24 / 24 失败被检出，0/1 成功误报**（四档维度 32/16/8/4 均如此） |
| **已验证的边界** | 只有 **1 局成功** → 误报率无分辨率；单任务、单种子；早触发占 20%（进度 <5%） |
| **上量要回答** | ① 跨任务还能不能检出 ② 误报率到底多少 ③ 多策略/DAgger 后是否稳定 ④ 触发时刻是否够准 |

**上量的三件事**（按阻塞顺序）：**补成功样本（定误报）** → **扩到多任务（定泛化）** →
**换策略/DAgger（定稳态）**。工程上必须先解决 **ANN 近邻检索** 和 **数据版本化**，否则单机跑不动。

## 2. 方法（已冻结）

见 `docs/ROUTE_C_OOD_SPEC.md` §2–§4。要点只列三条：

1. **统计量** $s(z)=\dfrac{\|z-z_{\pi(k)}\|}{\operatorname{median}_{j\in\pi(1..k)}\mathrm{dk}(z_j)}$，
   $k=5$，参考集**留一集**（同一条轨迹的帧不给彼此作保）。
2. **p 值** $p=\bigl(1+\#\{s_i^{\text{cal}}\ge s\}\bigr)/(n_{\text{cal}}+1)$，分裂共形，$n_{\text{cal}}\approx2{,}600$。
   保证是**边际**的：$\mathbb E[\text{ID 误判率}]\le\alpha$，对 OOD 无保证。
3. **判决** 滑窗 $W=5$、$M=3$；这一步**不继承** $\alpha$ 的保证，集级误报必须实测。

三种统计量的对照（同一数据、同一 $\alpha$）已量化：全局 kNN 在 32 维只剩 **8/24**，
LOF 23/24，进度条件 24/24 —— 这就是"为什么不能省掉局部归一化"的证据。

## 3. 已验证的结论（可直接引用）

| 结论 | 证据 |
|---|---|
| 判定有效 | 25 局（24 失败 / 1 成功）α=0.12：LOF **23/24**、进度条件 **24/24**，成功局均 0 误报 |
| 对维度不敏感（检出） | 32/16/8/4 四档 LOF 都 23–24/24 |
| 对维度敏感（时机） | 早触发次数 5/6/4/10；4 维开始误报成功局 → **下限 $d\ge8$** |
| 局部归一化是必需的 | 去掉后（全局 kNN）32 维掉到 8/24 |
| 判据不是"重建分"的副产物 | 重建分与潜空间统计量各自都能工作，但**只有后者可离线复算**（只需 `Z`） |
| 可复现 | 无随机性：同数据重复跑 $p$ 逐位相同；改 $\alpha$ 只改判决不改 $p$ |

## 5. 上量的口径与样本量

### 5.1 指标（只用这四个，不许再加）

| 指标 | 定义 | 为什么 |
|---|---|---|
| **集级捕获率** | 失败集中被触发的比例 | 主指标；用户能感知的是"这一局有没有被拦" |
| **集级误报率** | 成功集中被触发的比例 | 与捕获率配对报告，缺一不可 |
| **首触发进度** | 触发处 / 该集总长 | 区分"fail-fast"与"定位到出错步" |
| **提前量** | 首次触发到该集结束的秒数 | 给 CAP 接管留的时间窗口 |

统计口径：按**集**计数；区间用 **Wilson**（二项）；跨任务汇总用**按任务分层**再加权，
不做简单平均（任务难度差异会淹没效应）。

### 5.2 需要多少样本（这是上量规模的直接依据）

| 目的 | 需要的样本量 | 计算 |
|---|---|---|
| 误报率上界 <5% | **≥60 局成功**（0 误报时 Wilson 上界 4.9%） | $1.96^2/0.05^2\approx$ |
| 误报率上界 <2% | ≥380 局成功 | 同上 |
| 捕获率 90%±5% | ~139 局失败（Wilson 半宽 ≤5%） | $0.9\times0.1\times(1.96/0.05)^2$ |
| 区分 90% vs 95% 捕获率 | ~1,100 局失败 | 两比例检验、80% 功效 |
| 每任务至少 | ≥20 局失败 + ≥10 局成功 | 否则任务级结论无意义 |

**结论**：现在的 24 失败 / 1 成功只能支撑"方向正确"，**支撑不了任何误报率声明**。
上量第一优先级是**成功样本**——而成功样本恰恰是最贵的（要跑 VLA 评测）。

## 6. 预算（按实测系数推算）

**实测系数**（ws，单卡 RTX PRO 6000）：抽取 ≈ **50 s/集**（stride 5、三视角、含一次性编译）；
VAE 训练 ≈ 5 s/档；LOF 打分 25 局 vs 10,590 参考帧 ≈ **6–8 s/档**。

| 规模 | 抽取 | 存储（2048 维 float32） | 打分 | 备注 |
|---|---|---|---|---|
| 当前 | 25 集 ≈ 21 min | 0.3 GB | 6 s/档 | 已做 |
| 单任务扩到 100 成功 + 100 失败 | 200 集 ≈ 2.8 GPU·h | 0.25 GB | ~20 s/档 | 定误报 |
| 5 个任务 × 200 集 | 1,000 集 ≈ 14 GPU·h | 1.3 GB | 存疑（见下） | 定泛化 |
| 35 个任务 × 200 集 | 7,000 集 ≈ 97 GPU·h | 9 GB | 需 ANN | RoboDojo 全量 |

**打分是上量后的真瓶颈**：kNN 是 $O(n_{\text{eval}}\times n_{\text{ref}})$，
7,000 集时 $n_{\text{ref}}\approx1.1$M、$n_{\text{eval}}\approx1.1$M → $10^{12}$ 对，单机数天。
必须换索引（faiss/HNSW 或分桶+子采样到 5 万参考帧/任务），目标 **O(分钟)/档**。

**存储**：演示 embedding 可用 float16 压一半；页面只发**降采样后的 3D 坐标**，不发 2048 维。

## 8. 验收线（Gate）

| Gate | 条件 | 不满足则 |
|---|---|---|
| **G-A 误报** | ≥60 局成功上，集级误报 ≤5%（Wilson 上界） | 调 $\alpha$ 或换统计量，不上量 |
| **G-B 泛化** | ≥5 个任务，每任务捕获率 ≥80%，且任务间差 ≤20 pt | 补任务级校准（每任务独立 $\alpha$ 或分位数归一） |
| **G-C 稳态** | 同一任务换策略/DAgger 一轮后，误报不升 >3 pt | 参考集需按策略分桶 |
| **G-D 时机** | 首触发进度中位 <40%，且早触发（<5%）占比 <30% | 调 $k$/带宽，或引入"多帧证据 + 最短运行时长"下限 |

## 9. 风险

1. **可交换性**：演示集若跨多个布局/操作者，共形覆盖会破 → 需要**按任务（甚至按布局）分别校准**。
2. **参考集膨胀**：DAgger 后参考集变脏（含被纠正前的坏帧）→ 必须**只并入"被判定正常"的轨迹**。
3. **α 的可移植性**：$\alpha=0.12$ 是在本任务 + 本次校准集上选的；换任务/换数据量后最优值会移，
   **不接受跨任务直接沿用**。
4. **早触发**：占比 20–40%，本质是"整局异常"。若策略用它做错误定位会误判。
5. **成功样本贵**：误报率结论可能长期停在"上界 5%"，要有心理准备。

## 11. 需要拍板的决策点

1. **上量顺序**：先补成功样本（定误报）还是先铺任务数（定泛化）？我的建议是**先成功样本**——
   没有误报率，捕获率再高也不能上线。
2. **成功样本怎么来**：跑现成策略挑成功局 / 降低任务难度造成功 / 用人工遥操作补正样本？
   三者成本差一个量级。
3. **参考集粒度**：全局一套 / 每任务一套 / 每布局一套？我建议**每任务一套 + 300 帧/布局上限**。
4. **维度取值**：定 $d=32$（时机最好）还是 $d=8$（3D 可视化代表性 47%，页面更好看）？
   我建议**线上用 32、页面看 8**。
5. **页面在上量后怎么退**：评测集到几百局时，3D 点云会糊成一片。是否改成"任务→集"两级下钻？
