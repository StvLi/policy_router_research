## A. 定义类（阻塞开工）

### Q1 ·「CAP」到底指什么？GPT-6 Astra 怎么用？
- **选项**：`a` CAP = Code-as-Policies（强模型直接生成/调用技能代码执行）；`b` CAP = 别的含义（请说明）；`c` 先按 CaP 处理，用现成的 Qwen3.6-27B vLLM 当执行器，等 Astra 可用再换。
- **为什么重要**：A3（比全程 CAP 墙钟更短）是三条主张里最有把握的一条，但"全程 CAP"这条基线如果无法定义/无法调用，"更快"就没有对照物。另外 Astra 的成本与延迟直接决定兜底预算。
- **我的建议**：`c`。先按 CaP 语义实现兜底接口（`plan(skills) → execute`），执行器先用 6c GPU5 的 `qwen3.6-27b`（已有 vLLM，`127.0.0.1:8001`），把 Astra 作为可替换后端。
- 相关：`04` R10、`03` §5.1。

### Q2 ·「子任务」是语义类还是时序相位？
- **选项**：`a` S1 语义类（pick/place/move 的动词族，N=5–8）；`b` S2 时序相位（集内第 k 步，N 中位 7）；`c` 两者：S2 做路由判据，S1 做 prompt 检索键。
- **为什么重要**：实测（`scripts/caption_structure.py`）显示文本 K-means 只能得到 S1；而"符合某一子任务"这个路由语义需要 S2。选错则步骤 2 的产物与步骤 5 的用法对不上，而失败症状会被误判成"判别器不准"。
- **我的建议**：`c`。

### Q3 · 统计检验：KS 换成 conformal p 值，接受吗？
- **选项**：`a` 接受（conformal 做主决策，KS 保留 1 维诊断）；`b` 保留 KS，但改成逐维 + BH 校正 + block bootstrap（成本高、power 低）；`c` 换成能量距离/MMD；`d` 换成单高斯 + Mahalanobis χ²。
- **为什么重要**：`04` R1 的四条证据（维度、时序自相关、形状假设、多重比较）。其中**时序自相关**会让 KS 的 p 值稳定塌到 0，判别器退化成"永远不认识"，直接违背 A3。
- **我的建议**：`a`。这是本方案最可辩护的方法贡献，且实现比 KS 更简单。

### Q4 · VAE 架构：改为全局条件 VAE，接受吗？
- **选项**：`a` V3 全局条件 VAE（1 个模型，1.86M 帧）；`b` V2 每任务 1 个（35 个）；`c` V1 每子任务 1 个（≈350 个，原案）；`d` 放弃 VAE，用监督式编码器 + 密度模型。
- **为什么重要**：V1 有**两个**硬伤，第二个是致命的——不仅样本不够，**350 个独立 VAE 的潜空间互不可比**，"z 更像哪个子任务"这个问题本身未定义。
- **我的建议**：`a`，V2 留作消融。若 G2 探针显示学出来的潜空间不如冻结特征，则退 `d`。

### Q5 · 历史 `h` 的规则（用户说"之后给出"）
- **选项**：`a` `h = {t−50, t−12, t}`（2 s / 0.5 s / 0 s，与 `SUBTASK_VLM_SPEC.md` 冻结规格同构）；`b` `h = 连续 8 帧`（0.32 s）；`c` `h = 连续 25 帧`（1 s）；`d` `h = 单帧`；`e` 我来定，等我的规则。
- **为什么重要**：它决定编码器输入形状、时序模型、以及能不能跟既有 VLM 规格做干净对照。**缺这个，G2 探针写不出来。**
- **我的建议**：`a` 作为默认先跑通，规则给出后再替换（编码器接口按"支持任意时刻集合"设计，换 `h` 不改结构）。

### Q6 · 文本向量用哪个编码器？
- **选项**：`a` VLA 自己的 text encoder（与指令空间同构）；`b` 现成句向量模型（bge/e5/gte 类）；`c` 用户字面的"tokenizer + 池化"。
- **为什么重要**：`c` 没有句向量，池化后被功能词主导（实测质心前 4 词全是 `the/on/on_the/of`）；`a` 能让"检索到的模板"落在 VLA 真能理解的措辞空间里。
- **我的建议**：`a`，取不到就用 `b`。

### Q7 · 闭环评测时的相位标签从哪来（校准集问题）
- **选项**：`a` CAL-A 仿真状态 oracle（每 pilot 任务手写 20–40 行，如 `stack_bowls` 数已叠碗数）；`b` CAL-B 用开环演示数据校准，接受分布偏移；`c` CAL-C 用离线分类器打伪标签。
- **为什么重要**：conformal p 值必须有**同分布且带标签**的校准集，而官方评测不提供"当前第几阶段"。`b` 会让 p 值失效（这正是 R7），`c` 会系统性偏乐观。
- **我的建议**：`a`（只对 pilot 任务做），同时它也是 `01` H2 判决实验需要的基础设施——一份工两处用。
